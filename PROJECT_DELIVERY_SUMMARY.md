## 🚀 HOW TO DEPLOY IN 30 MINUTES

### Step 1: Quick Setup (5 minutes)
```bash
# Clone your repository
git clone <your-github-url>
cd eytra-iml-management

# Install dependencies
npm install
```

### Step 2: Create Supabase Project (5 minutes)
1. Go to supabase.com
2. Create new project
3. Copy URL and Anon Key

### Step 3: Configure & Deploy (20 minutes)

**Option A: Vercel (Easiest)**
1. Push code to GitHub
2. Go to vercel.com
3. Import GitHub repo
4. Add environment variables:
   ```
   VITE_SUPABASE_URL=your-url
   VITE_SUPABASE_ANON_KEY=your-key
   ```
5. Click Deploy
6. Your app is live in 2-3 minutes!

**Option B: Netlify**
1. Push code to GitHub
2. Go to netlify.com
3. Import GitHub repo
4. Build command: `npm run build`
5. Publish: `dist`
6. Add environment variables
7. Deploy
8. Your app is live!

**Option C: Traditional VPS**
1. Run: `npm run build`
2. SCP `dist/` folder to server
3. Configure nginx
4. Done!

### Step 4: Run Database Migrations (5 minutes)
1. In Supabase, go to SQL Editor
2. Paste content of `001_create_tables.sql`
3. Run it
4. Paste content of `002_seed_data.sql`
5. Run it
6. Done! 18 tables created + seeded with real products
